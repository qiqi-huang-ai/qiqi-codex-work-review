# Contributing

Thanks for helping improve Codex Review Workbench.

## Local development

1. Install Node.js 20 or later and Codex CLI.
2. Run `npm start`.
3. Open `http://127.0.0.1:4317`.
4. Run `npm test` before submitting a change.

## Pull requests

- Keep changes focused on Codex conversation review.
- Do not commit real conversation exports, generated reviews, credentials, or absolute private paths.
- Add or update tests for behavior changes.
- Document user-visible changes in `ROADMAP.md`.

## Privacy

Use only `data/demo/` fixtures in screenshots, issues, and pull requests. Assume all files under the user's Codex data directory are private.
